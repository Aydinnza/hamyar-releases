# همیار من — مخزنِ انتشار

این مخزن **فقط** فایلِ نصبیِ اپ («همیار من») را نگه می‌دارد. هیچ کدِ منبع و هیچ
کلید یا رمزی این‌جا نیست؛ مخزنِ اصلیِ پروژه خصوصی است.

## چرا این مخزن جداست؟

اپ خودش می‌تواند نسخهٔ تازه‌اش را بگیرد و نصب کند. برای آن، دو چیز لازم است:

1. **تنظیماتِ انتشار** — ردیفی به نام `app_release` در جدولِ `app_state` روی سرور
   (Appwrite) که می‌گوید آخرین نسخه کدام است، اجباری است یا توصیه‌ای، و آدرسِ
   فایل کجاست.
2. **لینکِ دانلودِ بدونِ احراز هویت** — همان چیزی که این مخزنِ عمومی فراهم می‌کند.
   اگر فایل داخلِ مخزنِ خصوصی می‌بود، برای دانلودش باید توکنِ دسترسی داخلِ اپ
   گذاشته می‌شد که کارِ ناامنی است (توکنِ داخلِ APK قابلِ استخراج است).

## قواعدِ انتشار

- هر فایل با همان **کلیدِ امضای نسخه‌های قبلی** امضا می‌شود و `versionCode` آن
  از نسخهٔ قبل **بزرگ‌تر** است، تا بدونِ حذفِ اپِ نصب‌شده نصب شود.
- نامِ فایل: `hamyar-<نسخه>.apk` — مثل `hamyar-1.66.apk`.
- نسخه‌ها به‌صورت Release با برچسبِ `v<نسخه>` منتشر می‌شوند
  (`v1.66` → فایلِ `hamyar-1.66.apk`).
- برای هر انتشار، `sha256` فایل در توضیحِ همان Release می‌آید.
- آخرین نسخه، هم‌زمان در ردیفِ `app_release` روی سرور اعلام می‌شود؛ اپ از همان
  ردیف باخبر می‌شود.
